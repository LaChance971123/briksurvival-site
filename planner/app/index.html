Updates & device copies

Before an update, save an editable backup inside the app. Importing a newer approved app file replaces the app software and keeps this origin’s household records.

Removing the imported app does not erase household records. Use Start over in the planner to replace those records. Clearing browser storage or removing the installed app can delete local copies; keep a downloaded backup.
